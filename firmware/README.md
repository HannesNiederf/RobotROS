# firmware

Nano Every firmware (PlatformIO, `platform = atmelmegaavr`, `board = nano_every`). Specification:
`docs/spec/spez_firmware_protokoll.md`.

Status: only the hardware-independent core exists so far.

- `lib/core/`: logic without Arduino headers, heap or exceptions (C++11, `-fno-exceptions -fno-rtti`).
  - `protocol.{h,cpp}`: serial protocol version 1 (parser, schema checks, frame formatting, payload writer).
  - `safety.{h,cpp}`: safety state machine of the DRIVE role with watchdogs, direction locks,
    ultrasonic classification and cliff confirmation.
  Same behaviour as the Python versions in `ros2_ws/src/robotros_bridge/robotros_bridge/core/`.
- `test/host/`: host tests (CMake). `cmake -S firmware/test/host -B build/fw && cmake --build build/fw && ctest --test-dir build/fw`.
  Optional `-DWITH_SANITIZERS=ON`. Unity/PlatformIO `native` can replace the small `check.h` later.
- `test/vectors/protocol_vectors.{json,txt}`: golden vectors for protocol version 1, generated by
  `tools/gen_protocol_vectors.py` (`--text` for the `.txt` used by the C++ tests); edit the generator, not the files.
- `test/vectors/safety_fsm.csv`: the safety state machine table of spec section 5.1, one line per row.
  Used by the Python safety logic and the C++ core tests. Changing it is a safety change: needs review.

Not done yet: HAL, application (`src/`), PID, hub state machine, PlatformIO project, build for the real board.
