# firmware

Nano Every firmware (PlatformIO, `platform = atmelmegaavr`, `board = nano_every`). Not started.
Planned layout and tests: `docs/spec/spez_firmware_protokoll.md`.

- `test/vectors/protocol_vectors.json`: golden vectors for the serial protocol version 1, shared with the
  Python bridge (`ros2_ws/src/robotros_bridge`) and fake_nano. Generated by `tools/gen_protocol_vectors.py`;
  edit the generator, not the JSON.
- `test/vectors/safety_fsm.csv`: the safety state machine table of spec section 5.1, one line per row.
  Used by the Python safety logic of fake_nano now and by the firmware host tests later. Safety change: needs review.
